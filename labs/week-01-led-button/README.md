# Неделя 1: LED и кнопка

## Цель

Научиться управлять светодиодом и читать состояние кнопки на ESP32.

## Компоненты

- ESP32
- Светодиод
- Резистор ~220 Ом (для LED)
- Кнопка
- Макетная плата и провода

## Схема подключения

- LED: анод → GPIO (например, GPIO 2) через резистор 220 Ом, катод → GND.
- Кнопка: один вывод → GPIO (например, GPIO 4), второй → GND.
- Внутренняя подтяжка: `INPUT_PULLUP` (нажатие = LOW).
