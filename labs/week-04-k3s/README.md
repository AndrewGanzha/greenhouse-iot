# Неделя 4: k3s

## Цель

Установить k3s на Raspberry Pi / мини-ПК и запустить первый под.

## Шаги

1. Подготовить устройство (ОС, сеть, SSH).
2. Установить k3s.
3. Проверить кластер: `kubectl get nodes`.
4. Запустить первый под: `kubectl run nginx --image=nginx`.
5. Проверить: `kubectl get pods`.
6. Настроить доступ к кластеру с рабочей машины.
