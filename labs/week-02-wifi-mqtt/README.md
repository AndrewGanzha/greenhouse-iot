# Неделя 2: WiFi и MQTT

## Цель

ESP32 подключается к WiFi и публикует сообщения в MQTT-брокер.

## Компоненты

- ESP32
- Локальный MQTT-брокер (Mosquitto в Docker)
- WiFi-сеть

## Шаги

1. Подключить ESP32 к WiFi (`WiFi.h`).
2. Подключиться к брокеру (`PubSubClient.h`).
3. Публиковать сообщение в топик, например `greenhouse/hello`.
4. Проверить приём через `mosquitto_sub`.
