# Greenhouse

Личная обучающая IoT-платформа на стыке электроники и Kubernetes.

Проект — это одновременно конспекты, лабораторные работы, прошивки ESP32,
инфраструктура и дневник ошибок. Всё в одном репозитории, всё своими словами.

## Цели обучения

Путь от простой схемы до GitOps-кластера:

1. **Схемы** — базовые схемы, закон Ома, чтение даташитов.
2. **ESP32** — прошивка, GPIO, сенсоры, WiFi.
3. **MQTT** — передача телеметрии по брокеру.
4. **Docker** — локальный стек (Mosquitto, InfluxDB, Grafana).
5. **k3s** — Kubernetes на мини-ПК / Raspberry Pi.
6. **GitOps** — ArgoCD/Flux, автоматизация доставки.

## Структура репозитория

| Папка | Назначение |
|-------|------------|
| `docs/` | Конспекты по теории: электроника, ESP32, Docker, Kubernetes, observability |
| `notes/` | Дневник: ошибки, инсайты, открытые вопросы |
| `labs/` | Лабораторные работы по неделям (схемы, код, результаты) |
| `edge/` | Прошивки ESP32, по одной на проект |
| `infra/` | Инфраструктура: `docker-compose` для локальной разработки, `k3s` для продакшена |
| `dashboards/` | JSON-дашборды Grafana |
| `gitops/` | Конфиги ArgoCD/Flux (позже) |
| `assets/` | Схемы и фотографии |
